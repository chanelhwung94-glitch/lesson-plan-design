# Ground Game · 大地遊戲（G）

A ground game is a large, camp-style activity — often 1–2 hours, many groups, indoor + outdoor stations, run by several volunteers. It is **not** a classroom lesson, so it has its own kit. Use `templates/ground-game.md`.

## How it relates to lessons
- **Games are built on lessons, not the other way round.** Start from one or more existing lessons and ask: what vocabulary, sentence patterns and ideas did kids learn there? The game makes them *use* those.
- **The game teaches its own rules, in its own session.** Lessons never spend time on game rules. The game session opens with a short vocabulary refresh + rules + grouping.
- Name the source lessons in the game's info block (by code or title).

## Design steps
1. **Learning link** — list the target words and sentence patterns from the source lessons. Every task and every spoken interaction in the game should use them (e.g. a sentence kids must say to complete a task: "Can I have ___, please?").
2. **Core goal & win logic** — one sentence kids can understand. Ideally the win logic mirrors something real about the topic, and no team can run away with it early.
3. **Structure** — a few rounds that repeat the same cycle, so kids learn the routine once. Difficulty rises each round.
4. **Roles** — small groups, each with a job (e.g. speaker, scorekeeper, runner, checker) so every child has something to do. In mixed-age groups, give older kids the roles that need more English and younger kids roles they can succeed in.
5. **Resources & scoring** — cards/tokens with point values, starting hands per team, rewards per task. **Do the arithmetic**: total cards needed = starting hands + all possible rewards − cards collected back, plus spares (~5 per type). Check no team can win or lose before the game really starts.
6. **Task bank** — questions graded by difficulty and by grade, each with answer and reward. Card format: `No. | grade level | question | answer | reward`.
7. **Events** — a few surprise events (shortages, windfalls) that make kids adjust and talk.
8. **Staffing** — who hosts, who keeps time, who runs each station, who hands out cards, who handles order and photos.
9. **Site** — indoor main room (announcements, scoring) + stations; draw or describe the layout and the walking routes.
10. **Safety** — group always moves together (no splitting), boundaries of the play area, running rules, weather plan, first-aid contact, headcount at every round change.
11. **Reflection** — end with 5 minutes connecting the game back to the lesson's big idea.

## Kit contents
| Part | Content |
|---|---|
| Game manual 遊戲手冊 | Info block, goal & win logic, rules, flow chart with times, roles, scoring tables, trade/task rules, end-of-game judging |
| Task bank 題庫 | Questions by round/difficulty, answers, rewards |
| Card specs & art 卡牌 | List of every card, counts incl. spares, printable art (colour + black-and-white versions) |
| Props & prep 道具清單 | Everything to print, cut, buy, set up |
| Site plan 場地安排 | Layout, stations, routes |
| Safety 安全注意事項 | As above |
| Notes | Source lessons, version history, what to change next time |

Student-facing cards and signs follow the same format conditions as lessons (標楷體; zhuyin when younger kids play).

## Checklist
- [ ] Every target word comes from a source lesson
- [ ] Rules can be explained quickly, ideally with a demo round
- [ ] Every child has a role; younger kids can succeed in theirs
- [ ] Card arithmetic checked, spares included
- [ ] Timeline adds up; buffer for moving between areas
- [ ] Staff roles cover every station and every moment
- [ ] Safety section complete; groups never split
- [ ] Reflection links back to the lesson
