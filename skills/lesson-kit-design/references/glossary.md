# Glossary · 名詞小辭典

Use these words consistently, and explain them in plain language the first time a beginner meets them.

| 名詞 | 意思 |
|---|---|
| 教案 Lesson plan | 給帶課志工看的上課說明：每一頁要做什麼、說什麼、大約多久 |
| 教材包 Lesson kit | 一堂課需要的全部東西：教案、簡報、學習單或活動、備註 |
| A / B / T / G | 範例代號：A = 4–6 年級進階版、B = 1–3 年級初階版、T = 不分年級或混齡的單一版本、G = 大地遊戲 |
| 系列性 Series | 同一個大主題分好幾堂課，前後要接起來，難度一課一課往上 |
| 單元性 Standalone | 一堂自己就完整的課，不依賴其他課 |
| 主線 Storyline | 串起整堂課的一個故事、旅程或問題 |
| 先備知識 Prior knowledge | 學生上這堂課之前，在學校已經學過的東西 |
| 課綱 Curriculum guidelines | 教育部規定各年級要學什麼（台灣是 108 課綱） |
| 鷹架 Scaffolding | 一步一步搭上去：先用學生會的，再往上加一點點新的 |
| IMGI 教學結構 | Instruct 教 → Model 示範 → Guided Practice 帶著練 → Independent Practice 自己練 |
| 靜態練習 / 動態練習 | 靜態：學習單，用紙筆記；動態：遊戲和動作，用身體記 |
| 超綱 | 練習或學習單用到這堂課沒教、學生也沒學過的東西 |
| ⚠️ 超出程度 | 刻意保留、比學生程度難的單字或概念，要標出來、加輔助、多練習 |
| 在地化 Localisation | 依上課地點換成學生熟悉的在地例子（選用） |
| 學習目標 Learning objectives | 下課後學生能做到的事，寫成「學生能…」 |
| 注音字型 / IVS | 每個字旁邊自動附注音的字型；IVS 是用來指定破音字讀音的隱形符號 |
| 字表 Word lists | 教育部國小 1000 單、1200 主題式單字、小學英檢（GEPT Kids）字表，用來判斷單字難度 |

## Three different "to check" markers 三種待辦標記
| 標記 | 用在哪裡 |
|---|---|
| 待核對 | **單字或程度**還沒確認（例如不確定這個字學生學過沒） |
| 待查證 | **事實**還沒確認（例如數字、歷史、地點資訊） |
| 待確認（上線前） | 教案最後的**上線前待辦清單**：沒確認完的事、還沒決定的事、設計者刻意保留的例外 |

## Tags for words outside the lists 字表以外的單字
Tag each key word with its source list. For words not on any list use one of: **主題名詞**（這堂課主題需要的專有名詞）or **延伸生活單字**（生活中常見、但不在字表的字）. If the word is also above the students' level, add **⚠️ 超出程度**. If you can't tell, use **待核對**.
