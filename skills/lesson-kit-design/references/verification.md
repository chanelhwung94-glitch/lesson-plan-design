# Verification & Consistency · 查證與一致性

## Facts and examples 事實查證
- Check every factual claim and real-world example (places, numbers, history, "this is the biggest…") against reliable sources: government, museum, encyclopaedia, official sites, curriculum handouts.
- If a claim can't be confirmed, **don't use it** — swap in an example you can confirm, or list it under 待確認（上線前）. A wrong fact taught by a volunteer is hard to undo.
- Local examples: when examples differ by region, find one per region (e.g. north / central / south) and confirm each.
- Note the source and licence of every photo or map; prefer free-to-use or self-made images.

## Sensitive or contested content 爭議與敏感內容
- Avoid examples tied to live territorial, political or religious disputes unless the lesson is explicitly about them and the designer has decided how to handle them. Prefer neutral examples that teach the same idea.
- Use geographic and factual terms neutrally; don't add political framing the designer didn't ask for.
- If a topic touches identity, conflict or hardship, ask the designer how they want it framed before drafting.

## Objective alignment 對齊學習目標 — the main check
The key question for every part of the kit: does it help students reach the learning objectives?
- Each objective → taught (which pages) → practised (which activity / worksheet item).
- Each page, activity and worksheet item → serves at least one objective; if none, cut it or tell the designer.
- Activities practise the objective at the right level (e.g. an objective "students can say the sentence" needs an activity where they actually say it).

## Consistency 一致性 — check before delivering
The same lesson exists in several places; they must agree.
- **English ↔ Chinese lesson plans:** same sections, same order, same content, same page references and times; no section translated in one and missing in the other.
- **Lesson plan ↔ slides:** same page numbers, same order, same sentences on screen as in the teacher script. If the designer edits slide narration, update the plan (and vice versa).
- **Word forms:** each key word appears in one form everywhere (e.g. base-form verbs on slides, cards, games and worksheet).
- **Vocabulary list ↔ activities ↔ worksheet:** every word practised is in the vocabulary list; every vocabulary word gets practised.
- **Times:** stage times add up to the lesson length; practice > 50%.
- **Advanced ↔ Basic:** the two levels differ by design — don't make them match. Each is checked against its own learning objectives; only shared elements (illustrations, story pieces) need to match where the designer intended.
- **Series:** this lesson still fits the series map; if the map changed, check earlier lessons.

## Known errors in source material
If the source (e.g. a printed book) has errors that can't be fixed, add a short note for volunteers on how to handle students' questions about them.
