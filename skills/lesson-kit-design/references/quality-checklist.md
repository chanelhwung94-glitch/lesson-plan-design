# Quality Checklist · 品質檢查

Run every item before a kit is called done. Report pass / fail / fix for each.

## Practice & time 練習與時間 — check first
- [ ] Practice (Guided + Independent practice, review games, worksheets) is **more than 50%** of the lesson; ideally 60–70%
- [ ] At least one of: worksheet (static) or activity practice (dynamic)
- [ ] Stage times are rough whole numbers and add up to the lesson length
- [ ] Content realistically fits — "10 minutes" really is 10 minutes of material
- [ ] Fallback names what to cut first (teaching content, optional video) and which single activity stays if time runs short

## Design 設計
- [ ] One version for a single mixed-grade class (pitched at the youngest grade), or two versions for two separate groups
- [ ] Every learning objective is taught and practised; every page and activity serves at least one objective
- [ ] Lesson type (series / standalone) stated in the info card, with links to other lessons
- [ ] Series: matches its slot in the series map; builds on earlier lessons; difficulty steps up by one; review bridge at the start
- [ ] Standalone: self-contained
- [ ] Curriculum research done: prior-knowledge table with sources
- [ ] Advanced designed first; Basic simplified from it, to a level that matches what Basic grades have learned at school
- [ ] One storyline; teaching covers only what it needs — not a full subject lesson
- [ ] Instruct → Model → Guided → Independent, with one demonstration
- [ ] If the content is place-based: localisation slot marked (examples by region; volunteer talks about the nearest). Not needed otherwise

## Level 程度
- [ ] Vocabulary checked against the word lists, sources tagged; unconfirmed items marked 待核對
- [ ] Above-level words and concepts marked ⚠️ 超出程度, with extra support and practice time planned
- [ ] Mixed-grade groups: every concept has been learned by the youngest grade
- [ ] No 超綱: every activity and worksheet item uses only taught or known content

## Accuracy & consistency 查證與一致性 (`verification.md`)
- [ ] Facts and examples verified; unverifiable ones removed or listed under 待確認
- [ ] No contested or sensitive framing the designer hasn't decided on
- [ ] Image and map sources noted
- [ ] No students' names or photos in materials or AI tools; no textbook text, pictures or exercises copied
- [ ] Lesson plan ↔ slides ↔ cards ↔ worksheet agree (page numbers, sentences, word forms)

## Volunteer-readiness 志工可用
- [ ] Every slide/range has goal / bilingual script / method / expected responses
- [ ] Anticipated questions with suggested answers; background notes where kids may ask "why"
- [ ] Activity rules explainable in about one minute; rounds and scoring clear
- [ ] Materials list complete, including prep and tools to test before class

## Format & production 格式與製作
- [ ] All Chinese in 標楷體; English/numbers in Times New Roman (documents)
- [ ] Class includes any grade 1–3 students: zhuyin on all student-facing Chinese; polyphonic characters checked
- [ ] Worksheet: student version + volunteer/answer version
- [ ] A4, white background, prints well in black and white
- [ ] House style applied (codes, file names, branding)
- [ ] Lesson plan in English and Chinese, same structure and format, content checked section by section
- [ ] .docx + .pdf saved; fonts embedded

## Open items 待確認
- [ ] 待確認（上線前） list is empty, or everything left on it is agreed with the designer
- [ ] All ⚖️ decisions resolved by the designer
