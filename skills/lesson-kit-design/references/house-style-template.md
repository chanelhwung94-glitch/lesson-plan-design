# House Style · 團隊格式設定

Fill this in with your team's own conventions. If a team has its own copy (e.g. a members-only file), use that instead. Fonts, zhuyin and page layout are **not** here — they're required conditions in `lesson-plan.md` for every kit.

Below are YIT's level-code and file-naming systems as a working example; keep, adapt or replace them.

## Level codes 教材代號 (example)
Format: `{number}{level}`, plus `-1` / `-2` for a topic split across lessons.

| Suffix | Meaning |
|---|---|
| A | Advanced — grades 4–6 |
| B | Basic — grades 1–3 |
| T | Together — one version for a mixed-grade class, pitched at the youngest grade |
| G | Ground game 大地遊戲 (outdoor / camp-wide, not a classroom lesson) |

e.g. `101A`, `101B`, `102A-1`, `103G`. New lessons take the next unused number — check for collisions.

A G kit replaces slides/plan with: rules + flow, props list, site layout, safety notes.

## File names 檔名 (example)
`{code}_{topic}_{Advanced|Basic|Together}_{type}[_注音版].{ext}` — underscores, level in full, code first.
e.g. `101B_動物的家_Basic_學習單_注音版.docx`. Save the editable file and a PDF side by side.

## Kit folder (example)
