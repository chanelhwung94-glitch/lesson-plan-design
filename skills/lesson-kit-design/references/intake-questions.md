# Intake Questions · 需求設定的提問

Ask **every** question below — each one changes the design. Many designers are beginners, so never ask a bare question: give each one **why we ask (為什麼問)**, a hint for **how to think about it if you're not sure (不確定時可以這樣想)**, and the **default (預設)** they can simply accept. The goal is that answering the questions teaches the designer how to think about a lesson.

Ask in small groups (about 3–4 questions per message, in the order below) so it doesn't feel like a form. If the designer answers "不知道", explain the hint again with a concrete example and offer the default — don't skip the question.

Start with the note on what "already learned" is based on (see SKILL.md step 1).

## Group 1 — What kind of lesson 課程與主題

**1. 起點：新主題、改既有教案、還是從現成簡報反推教案？**
- 為什麼問：新主題是從零開始設計。另外兩種通常是為了「讓別人也能用」：
  - 改既有教案：以前做的教案常常比較粗糙，沒有照語言教學的邏輯（先教、示範、帶著練、自己練）設計。改版是把它整理好，讓沒參與設計的人也能照著教。要先讀舊教案，保留能用的部分。
  - 從簡報反推教案：有時候設計者只是為了自己上課做了一份簡報，沒有教案，別人拿到也不知道怎麼教、為什麼這樣排。反推教案是把設計者腦中的想法寫下來，讓第三個人也能接手。
- 不確定時：手上什麼都沒有，就是「新主題」；有舊教案或簡報，想一想這次的目的是不是「交給別人教」。
- 預設：新主題

**2. 這堂是一般課堂，還是大地遊戲？之後會不會接大地遊戲？**
- 為什麼問：這題要一開始就問，因為兩種課的設計完全不同。
  - 大地遊戲那一堂整堂都是遊戲，沒有教學（lecture）的部分：前面只會複習教過的東西、介紹遊戲規則，接著就是設計各關卡和跑關流程（見 `ground-game.md`）。
  - 如果是一般課堂、之後會接大地遊戲，這堂課要先把遊戲會用到的單字和句型教好、練好；遊戲規則留到遊戲時段再教。
- 不確定時：問帶隊的人或看活動流程表，有沒有排「闖關」或「大地遊戲」。沒聽說有，就是一般課堂、不接大地遊戲。
- 預設：一般課堂，不接大地遊戲

**3. 這堂課是系列性還是單元性？**
- 為什麼問：兩種的設計重點完全不同。
  - 系列性：大主題通常很廣，要拆成好幾堂課，每堂只講一個面向。系列有一個大的學習目標，每一堂也有自己的學習目標。設計時要顧到前後課的連貫，知識和難度要一課一課往上搭（scaffolding）。所以要先定好系列大綱，再設計每一堂。
  - 單元性：沒有前後課可以依靠，這一堂就要完整，一堂課裡把要傳達的內容全部帶到。
- 不確定時：這堂課上完，還會不會有下一堂接著同一個大主題？會的話就是系列性。
- 預設：無，必須回答

**4. 主題或素材是什麼？（主題、繪本、舊教案、簡報…）**
- 為什麼問：設計者一開始通常只帶一個主題來，而主題常常太大（例如「科學」「環境」），一堂課做不完。先確認是系列性還是單元性，再把主題一層一層縮小到一堂課講得完、而且非常明確的範圍（例如「科學」→「植物」→「種子怎麼長成植物」）。主題越明確，主線越清楚，也越容易決定要查哪些課綱和課本。
- 不確定時：先想「下課時希望學生能說出哪一句話」；如果一句話說不完，代表主題還太大，可以再縮小，或拆成系列。
- 預設：無，必須回答

## Group 2 — Students and time 學生與時間

**5. 學生是誰（幾年級、什麼程度）？要分成幾個程度？同一班有不同程度的學生一起上嗎？**
- 為什麼問：設計者很容易高估低年級的英文程度和吸收速度，尤其是自己英文不錯、離國小已經很久、或還沒有太多國小教學經驗的人。所以要先講清楚年級，才知道單字難度、句型長度、要不要加注音，還有要做一個版本還是兩個版本。A 版（進階）和 B 版（初階）怎麼分由你決定：預設是台灣國小的 A 版 4–6 年級、B 版 1–3 年級，但你也可以照年齡、英文程度、學校類型等自己的標準分。同一班混了不同程度的學生時，內容要以「程度最低的學生也聽得懂」為準，不然他們會跟不上、整堂課卡住。
- 不確定時：問學校或帶隊的人，這堂課是哪幾班一起上。拿不準難度時，想像你教的是一年級最安靜的那個孩子。
- 預設：台灣國小，A 版 4–6 年級、B 版 1–3 年級（年級必須回答）

**6. 學生的英文程度大概如何？是偏鄉還是一般公立學校？**
- 為什麼問：同年級的學生程度可能差很多。程度會影響要用多少中文輔助、單字放多少。
- 不確定時：以「學校英文課的進度」為準，不要假設學生有補習。
- 預設：依學校進度、需要中文輔助

**7. 課堂多長？**
- 為什麼問：每個地方的一堂課長度不一樣：國小一節課通常 40 分鐘，國高中通常 50 分鐘，補習班和校外課程大多是 60 分鐘。預設的 60 分鐘不一定符合你的狀況，要照實際時間設計。時間決定能教多少：練習要超過一半，所以時間越短，能教的新內容越少。
- 不確定時：問學校一節課多長，或看營隊的課表。
- 預設：60 分鐘

## Group 3 — Room and practice 場地與練習

**8. 班上大約幾個人？有幾位老師或志工？教室有沒有空間讓學生站起來動？**
- 為什麼問：
  - 人數決定怎麼分組（幾個人一組、分幾組），也決定需要幾位老師或志工。
  - 小班老師顧得到每個人，活動可以比較激烈、比較集中；大班比較難控場，學生自己做的練習（獨立練習）要特別評估老師看不看得住。
  - 空間太小就不能玩跑跳或動態遊戲；有些學校只能在教室裡上，不能到室外活動。
- 不確定時：問學校班上人數和上課地點，再問帶課的有幾個人。
- 預設：一般教室、約 25 人、1–2 位帶課的人、可以在座位旁站起來

**9. 有沒有平板、電腦、投影機、網路？**
- 為什麼問：有些地方沒有網路或電子產品。Kahoot 這類活動需要平板和網路，沒有設備就要改用學習單或不需要設備的遊戲。先確認，才不會到現場才發現活動不能用。
- 不確定時：問學校；拿不準時以「只有投影機」來設計最保險，需要網路的活動準備一個不用網路的替代方案。
- 預設：只有投影機和電腦

**10. 練習想用學習單、活動，還是兩個都要？**
- 為什麼問：看課程的類型和主題內容來選。學習單是靜態、紙筆記憶，適合知識型、需要學生記住東西的課；活動是動態、肢體記憶，適合要開口說、要動的內容，例如文化主題的課就需要讓學生有身歷其境的體驗。至少要一種，練習時間要超過一半。
- 不確定時：想一想「這堂課最重要的是讓學生記住，還是讓學生體驗、開口用」。記住→學習單為主；體驗、開口→活動為主；兩個都重要就兩個都用。
- 預設：兩個都要

## Group 4 — Production 製作

**11. 簡報用什麼工具做？有沒有喜歡的模板或以前做過的簡報可以參考？**
- 為什麼問：每個人習慣的工具不一樣，有人擅長 Google Slides，有人用 Canva 或 PowerPoint，就用你最順手的工具。如果你對版面有自己的要求，或以前做過很滿意的教材想沿用，提供模板，簡報就會照那個樣子做。
- 不確定時：用你最常用的工具；沒有模板也可以，會先給每一頁的內容和畫面說明。
- 預設：Canva，沒有模板

**12. 有沒有團隊或機構的格式要套用（教材代號、檔名、logo、浮水印、配色）？**
- 為什麼問：有團隊的話，交付的檔案要照團隊規範命名和排版，教材之間才會一致，也方便整理。沒有團隊、自己做的話，這題可以略過。
- 不確定時：問團隊負責教材的人；沒有的話就用 `house-style-template.md` 的範例格式，或直接略過。
- 預設：沒有團隊格式，用範例格式

**13. 注音字型裝好了嗎？（班上有 1–3 年級才需要）**
- 為什麼問：新手第一次設計時常常忘記，低年級的孩子很多國字還不會讀，學生用的材料每個字都要加注音，不然看不懂。注音字型是台灣特有的，很多國家和地區的電腦沒有內建，也比較難找，要先下載、裝好。
- 不確定時：看 `zhuyin.md` 開頭的三步驟。
- 預設：還沒裝，需要時會提醒
