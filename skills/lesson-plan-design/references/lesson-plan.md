# Lesson Plan · 教案

The lesson plan is written for the **volunteer who teaches**, not for students. It succeeds if a volunteer can teach from it alone: they know what to do in each part, roughly how long it takes, what kids will likely say, and what to do when things go off-plan. Use `templates/lesson-plan.md`.

## Required formatting conditions 教案格式條件

These apply to every lesson plan and every student-facing document in the kit (worksheets, slides):

1. **標楷體 for all Chinese text.** It's the standard-form Kaishu typeface Taiwanese kids learn to write from at school, so it matches what they see in textbooks and is easiest for them to read. English and numbers use Times New Roman in documents (a bold sans-serif is fine on slides for on-screen readability). In mixed paragraphs, set Chinese characters and Latin text separately rather than one font for the whole paragraph.
2. **Zhuyin 注音 for younger grades.** Whenever the class includes any grade 1–3 students, every Chinese character on student-facing material gets zhuyin, placed to the **right** of the character as small vertical text (about half the character's size). Grades 4–6 only: no zhuyin. (Default for Taiwanese elementary schools; other learners use the reading support that fits them.) Use a zhuyin font and check polyphonic characters — see `zhuyin.md`.
3. **A4 portrait, white background, minimal layout.** Plain-text section titles, no coloured bars, gradients or striped tables — it prints cleanly in black and white at schools.

## Sections (in this order)

### 1. Info card 教案基本資料 — top of the document
Short lines a volunteer can scan in five seconds:
- Level & grades (e.g. Advanced, grades 4–6)
- Lesson length
- Designer
- Matching materials (slides / worksheet / game names or codes)
- **Lesson type 系列性／單元性** and **links to other lessons**, up front — volunteers and schedulers need it before planning a visit. Use a small table:

| 教案 Lesson | 關係 Relationship | 排課建議 Scheduling |
|---|---|---|
| This lesson | e.g. chapter 1, no prerequisite | can be taught alone / must follow ___ |
| Other level (A/B) | same storyline? shared illustrations? | e.g. lower grades take B, upper grades take A on the same day |
| Next lesson in the series | what it builds on from this one | e.g. teach this first |

### 2. Outline 核心脈絡與主題說明
One paragraph: the core concept for this level, the storyline that carries the lesson, and the rough teaching/practice split.

Then the **prior-knowledge table 學生先備知識** from the curriculum research (`curriculum-research.md`) — what school has taught each grade about this topic and what that means for the lesson — with sources underneath.

### 3. Learning objectives 學習目標
About four, each one ability, written as "Students can …" / 「學生能…」. Typically cover: recognising/reading the key words, using the core sentence pattern, one concept/reasoning goal, and one attitude/value goal.

The objectives drive the rest of the plan. Write them before the step-by-step guide, then check alignment: every objective has teaching pages **and** a practice activity or worksheet item that practises it; every page and activity serves at least one objective. Mark which objective(s) each stage and activity serves (e.g. 「對應目標 1、3」).

### 4. Key vocabulary 核心單字
Each word with Chinese meaning and the source list it comes from (e.g. MOE 1000 / MOE 1200 / GEPT Kids / proper noun / everyday extension / advanced topic word). Tag words not on any list as 主題名詞 or 延伸生活單字; if a word is also above the students' level, add ⚠️ 超出程度 so volunteers know to give extra support and more practice time; if unsure, 待核對 (see `glossary.md`).

### 5. Key teaching points 教學重點
About three short paragraphs on the things volunteers most easily miss — the "why" behind the design, not just the "what".

### 6. Step-by-step guide 逐頁教學指引 — the main body
Split into stages that follow **Instruct → Model → Guided Practice → Independent Practice**, e.g.:
- Warm-up 引起動機 (series lessons: a short review bridge to the previous lesson)
- Instruct & Model 教學與示範 — one demonstration, not one per item
- Guided Practice 引導練習
- Independent Practice 獨立練習
- Wrap-up 收尾

If the lesson has a **localisation slot 在地化** (optional — place-based content only), mark those pages: tell the volunteer to talk only about the example nearest the school, and what to prepare (e.g. a local map) before class.

Give each stage a rough whole-number time (e.g. "約 10 分鐘"). Avoid minute-level schedules — they look precise but volunteers can't follow them in a real classroom. Check the stage times add up to the lesson length (default 60 minutes) and that **practice is more than half** (aim ~60–70%). Practice = Guided Practice + Independent Practice + review games/worksheets (warm-up, teaching and wrap-up don't count). A typical 60-minute split: warm-up ~5, teaching ~15, practice ~35, wrap-up ~5.

For each slide or slide range:
```
Page X–Y: [title]
● 教學目標 Goal:
● 教師引導句 Teacher script: 「中文話術」 + "English sentence"
● 教學方法 Method: (show, ask, repeat after me, gesture, pair work…)
● 學生預期反應 Expected responses:
```
Teacher scripts are always bilingual — volunteers mix both languages in class.

Optional per page: **教學背景補充（志工需了解但不必教）** — background a curious kid might ask about, so the volunteer can answer without teaching it.

### 7. Anticipated questions 預期學生提問
At least one Q + suggested answer per new concept.

### 8. Fallbacks 變通方案
```
如果時間不夠 If short on time: what to skip, in priority order
如果學生反應冷 If the class is quiet: movement, gestures, start the game earlier
如果學生太熱烈 If very excited: accept it, then pull back; save extension questions for after class
```

### 9. Materials list 物品清單
Everything to bring or prepare: printed worksheets (how many, which version), devices and tools to test, cards to print and cut, props, localisation prep (if any). Prep belongs here, not scattered through the steps.

### 待確認（上線前） Open items before release
A short checklist at the end: facts still to verify, image sources, titles not final, decisions pending. Empty it before the kit is published.

## Versions
- One plan **per version**: a single plan for a mixed-grade class, or one per level when there are two separate groups. Write the Advanced plan first, then derive the Basic plan by simplifying it (see SKILL.md step 3) — fewer words, simpler patterns, more movement, shorter scripts. The Basic plan gets its **own, simpler learning objectives**. A and B are not expected to match: check each version against its own objectives.
- **Two language versions, both required: English and Chinese 中文.** Same sections in the same order, same tables, same page references, same file format (.docx + .pdf for each). The content is the same; when one changes, update the other, and compare them section by section before delivering.
- Build plans as Word documents (.docx) the designer can edit and comment on (or Google Docs if the team works there); deliver .docx + .pdf at the end.

## Common mistakes
| ❌ | ✅ |
|---|---|
| "Teach giraffe" with no how | goal / script / method / expected response |
| Chinese-only or English-only scripts | bilingual scripts |
| Paper says 10 min, content needs 20 | trim content until it fits; favour practice |
| Lesson links written at the end | in the info card at the top |
| Teaching drifts into a full subject lesson | teach only what the storyline needs |
| Activity uses words never taught (超綱) | cut it or move it to a later lesson |
| Minute-by-minute timing | rough whole numbers per stage |
| No materials list | full list incl. prep |
