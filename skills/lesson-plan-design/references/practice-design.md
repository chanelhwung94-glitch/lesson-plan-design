# Practice Design · 練習設計

Practice is more than half the lesson, so most design effort goes here. Use `templates/activity.md` for each activity write-up.

## 1. Propose a menu, let the designer choose
Offer 3–5 candidate activities in a table, then let the designer pick, change the rules and set the order.

| # | Activity | How it works | Practises | Time |
|---|---|---|---|---|

Mix static (worksheet: reading, writing, matching, drawing) and dynamic (movement, listening-and-reacting, card games, relays, role-play). Kahoot or other quiz apps are one option among many — only when the school has devices.

Designers often describe a game idea loosely ("everyone holds a card, stand up when you hear your word"). Turn it into clear rules and rounds, then check it with them.

## 2. Check every candidate
- **No 超綱.** It only uses words, patterns and ideas taught in this lesson or already known. If an activity needs untaught content, cut it or suggest moving it to a later lesson where that content is taught.
- **Fits the level.** Advanced activities use and extend; Basic versions are simplified (recognise/name, more movement).
- **Fits the room:** class size, space to move, devices, noise.
- **Rules explainable in about a minute.** Longer rules belong in a separate game session.

## 3. Order and timing
- Order easier → harder (e.g. recognition game first, then a faster listening/reaction game).
- Give each activity a rough time; together they keep practice > 50%.
- Name the fallback: **if time runs short, play only one** — say which.
- Harder rounds inside one game work well: same game, rising difficulty (slow and in order → shuffled → faster / several keywords at once).

## 4. Write-up for each activity
Goal · time · groups · materials & prep · bilingual rules · rounds · how to start/stop · scoring (what counts as correct — e.g. English word + Chinese meaning) · variations (easier/harder, big/small class, no space) · volunteer tips (pacing, light rewards, review the most-missed item).

## 5. Reusable tools
Prefer tools volunteers can reuse across lessons (e.g. one digital card-match page with selectable decks) over one-off setups. Note in the materials list what to test before class.

## Kahoot / quiz specifics (if chosen)
~10–12 questions for older groups, 6–8 for younger; 30 s each, 45 s for reasoning; easy → hard; correct answers spread across A–D; deliver `.md` + bulk-import `.csv` (`templates/kahoot.csv`).
